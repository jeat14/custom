# admin-verification-email environment

Set these secrets in Supabase (Edge Function secrets):

- SUPABASE_URL
- SUPABASE_SERVICE_ROLE_KEY
- RESEND_API_KEY (optional; enables emails)
- RESEND_FROM_EMAIL (optional; required if RESEND_API_KEY is set)
- APP_URL (optional; recommended: https://app.evernest.com/login)
